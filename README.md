# 주오 돌잔치 모바일 초대장

정적 파일만으로 동작합니다 (index.html + images/).

## GitLab Pages로 올리기
1. GitLab에서 새 프로젝트(public) 생성
2. 이 폴더의 파일을 모두 커밋/푸시 (.gitlab-ci.yml 포함)
3. 파이프라인이 끝나면 Settings > Pages 에서 주소 확인
   (보통 https://<계정>.gitlab.io/<프로젝트명>/ )

## 다른 곳에 올리기
GitHub Pages, Netlify, Vercel 등 정적 호스팅 어디든 index.html과 images/ 폴더만 그대로 올리면 됩니다.
